# 工尺谱的数据与表达范围

简牍提供谱字、板眼、音区、唱词、分句和一字多音对应的编辑与排版。常用谱字候选为合、四、一、上、尺、工、凡、六、五、乙；也允许自定义少量谱字或附加标注。音区字段是显式文字标注，不自动改变谱字字形。

不同乐种和谱本的符号、口传和节奏表达存在差异，因此不把所有工尺谱硬换算成同一套音高或时值。板眼按用户所录原谱呈现。示例只演示排版，没有对应真实曲目，也不宣称可据此自动演奏。

这里的对应关系通过记录身份与唱词跨度保存，移动和分页均以对应组为单位。横排时唱词单元格横向合并，竖排时纵向合并；同一唱词的关联谱字不会跨组切断。Word 表格保留实际文字与合并结构，不把谱面制作成整页图片。

术语与范围参考：[中国非物质文化遗产网：工尺谱](https://www.ihchina.cn/art/detail/id/7507.html)、[南音文化生态：不同记谱体系的时值表达差异](https://www.ihchina.cn/Article/Index/detail?id=18493)。这些资料用于确定功能边界，并非本项目示例曲谱的来源。
