# Bamboo 0.7.0 验证记录

验证日期：2026-09-10。

## 检查范围

完整检查共 243 个用例，包含 15 个真实浏览器测试。覆盖独立元素开关、页面样式、编号引用、Word 域结构及导入回读；包含 40 组固定种子随机混合文档。专用文档检查覆盖精确金额、世代与循环关系、工尺谱一字多音、横竖导出、真实 Word 字段回读和编辑恢复。最终调整多栏眉批断行后，25 项手稿与浏览器相关检查再次通过。

## 0.7.0 朱批手稿验收

`examples/manuscript-notes.json` 包含黑字竖排正文、红色句读、栏间长旁批和两栏眉批。固定 PDF 与 LibreOffice 渲染 DOCX 均为两页，逐页检查了字形、注释区域、断栏和正文间距。两种输出提取的红色字符逐页一致：第一页 93 字，第二页 60 字（包含句读）。眉批采用右栏六字、左栏七字的分配；正文和批注均为真实文字。

长批注检查覆盖横竖方向、栏间避让、续栏、续页和批注专页，并逐字核对内容没有丢失。另以 300 字连续正文检查跨页锚点：固定 PDF 和实际渲染的 DOCX 均为五页，指定的 11 字朱批均出现在第三页。此检查修正了竖排 Word 字距与字体外框舍入导致的少排一栏问题。

浏览器实际检查打开样例、字体加载、从右向左对页预览、点击朱批修改内容与颜色、撤销，以及句读颜色独立设置。页面样式库现有 17 种样式，新增“朱批手稿”。样稿使用霞鹜文楷；字体通过明确的下载操作安装到本机缓存，源码包不包含字体文件。

DOCX 中正文可以流式编辑，批注使用可编辑文字框。长批注的避让和续排由简牍在导出时计算；Word 修改正文或纸张后不会自动运行同一套算法，应在简牍原稿中修改并重新导出。以上实际渲染结果来自 LibreOffice，不能视为所有 Word、WPS 版本的逐字一致保证。

同时验证了源码包与 wheel 构建成功，wheel 元数据声明 Apache-2.0，并包含 LICENSE、NOTICE 和第三方组件说明。PyMuPDF 依赖保持不变，第三方许可证单独记录。

工尺谱五句四十个谱字的示例包含一字多音对应。固定 PDF 和 LibreOffice 渲染 DOCX 在横排、竖排下均为两页，检查了谱字、唱词、板眼、分句与合并跨度。Word 回导读取实际修改的唱词及横向、纵向合并关系。浏览器检查包括组内删除后跨度缩短、对应组整体移动、方向切换、撤销和三种格式下载。

功能名称统一为“册簿”，字段使用“金额”“物品”。保存格式的 gift 标识和既有接口保持兼容。尚未实现的其他通用排版能力仍按文档所列边界处理。

浏览器检查实际操作纸面输入、连续输入顺序、回车分段、跨段选区、拖选添加短旁注、组合输入只提交一次、撤销重做、刷新恢复、普通文本打开及 PDF/HTML/DOCX 下载。另检查无令牌、跨站和旧版本请求被拒绝。

示例使用本机宋体进行字体覆盖检查和子集化；字体文件不放入源码。当前环境的核心依赖为 Python 3.9、PyMuPDF、python-docx 与 fontTools。

## 0.5.0 样式验收

`examples/styles.json` 包含题签、朱栏序言、诗文疏排和典籍正文四篇，含署名落款、段内换行、朱文和白文方印。固定 PDF、Chromium 打印 HTML 与 LibreOffice 渲染 DOCX 都输出 4 页，逐页检查了双线题签框、正文、颜色与印文。封面使用窄幅纸张，后续篇章使用宽幅纸张。

另检查一份 3 页混排文档：题签封面、竖排正文、横排正文依次分节，Word 实际渲染保留各自的文字方向。纸张尺寸经 OOXML 与 PDF 检查，阅读器输出存在小于 1pt 的尺寸舍入差异。

自动化用例验证复用样式全局更新、当前篇章设置与撤销、段内换行后的批注锚点、封面插入保留原文、字号超限时保留输入、分篇页码、印文回读、Word 修改后的真实封面文字优先、不同纸张的 HTML 打印和可选图片 DOCX 尺寸。UI 用例直接操作样式、篇章、封面与印章，并重新打开保存文档。

印章目前使用普通文档字体；题签和印章的跨阅读器边框、位置及字距仍可能有细微差异。未宣称篆刻字形生成或任意 Word 编辑后的像素一致。

## 增删重排验收

在已导出的 Word 文件中插入已有文字段落，不重新运行排版引擎，再由阅读器渲染：横排文档由 2 页自动增至 3 页，竖排朱批文档由 1 页自动增至 7 页。重复段落中的原生 ruby 随文字出现在各页；原有长旁批和眉批迁移到其所在段落的页面。

这证明正文是可重排的文字流，不是按固定页拆开的图片或逐字框。它不证明长批注能逐字更新段内位置或自动跨页续框；这些限制仍会写入导出警告。

当前实际渲染使用所选宋体及 LibreOffice；浏览器验收使用 Chromium。未声称在所有 Microsoft Word、WPS 或移动端版本上完成测试。相同页数也不等同于逐字位置完全一致。

## 如何复查

```sh
python -m pytest -q
BAMBOO_BROWSER_TEST=1 python -m pytest tests/test_editor_browser.py -q
python -m bamboo edit
python -m bamboo check examples/daodejing.bamboo
python -m bamboo render examples/daodejing.bamboo -o output/flow --name daodejing
python -m bamboo render examples/horizontal.bamboo -o output/horizontal --name horizontal
python -m bamboo render examples/annotations.json -o output/annotations --name annotations
python -m bamboo render examples/custom.json -o output/custom --name custom
```

自动化测试不等同于实际渲染验收。更换字体、修改分页或 DOCX 页面结构后，应重新检查整份样书的每一页，特别是夹注续栏、版心长标题和尾页内容。`manifest.json` 记录源文摘要、字体摘要、各输出文件的字节数与 SHA-256，可用于确认检查的文件与交付的文件一致。


## 页面样式扩展验收

样式库从 6 种扩展为 16 种。新增用例验证全部样式参数互不重复、16 种样式均能导出 PDF/HTML/原生 DOCX、Word 纸张尺寸与横竖方向及分栏设置正确、真实正文能够回读。浏览器实际预览全部 16 张卡片，筛选横排类别，依次应用 10 种新样式，检查正文与段落标识保持、取消无修改、撤销与刷新恢复，以及只从当前段落另起篇章。

`examples/page-styles.json` 的 PDF 和 LibreOffice 渲染的 DOCX 均为 16 页。逐页检查了单页、双面、大小开本、横竖方向、纸色、界栏与文字，没有把正文转换成图片。最终字位和分页仍由 Word 阅读器计算，检查不代表所有阅读器像素一致。


## 册簿与命名更新（2026-09-09）

册簿覆盖录入、编辑、排序、删除、精确金额与大写、分页小计和总计、横竖排及保存恢复。实际浏览器验证纸面点击回到记录、方向切换、撤销和三种格式下载。横排与竖排的九条记录样例在固定 PDF 与 LibreOffice 渲染 DOCX 中均为两页，检查了所有记录及合计均存在。Word 标签字段回读读取实际修改金额，重新计算合计。

竖排 Word 中连续西文和阿拉伯数字的朝向由阅读器处理，和固定布局的逐字直立显示仍可能不同。页小计在 Word 中按导出记录分组保留，修改后应回导重新排版。


## 族谱验收（2026-09-09）

三代五人样例生成两张世系图和五页人物传记，固定 PDF 与 LibreOffice 渲染 DOCX 均为七页。检查了亲子与配偶连线、父母子女的跨页位置提示及传记文字。自动化验证了亲属缺失、循环、世代冲突、双向配偶关系、横竖图形、实际 Word 记录回读；浏览器验证录入、关联、循环拒绝与纸面定位。
