# 特殊版式的表达与边界

## 已实现样式

| 样式 | 表达方式 | 样书 |
| --- | --- | --- |
| 黑字竖排、双面版心、双鱼尾、双边框 | 方向、模板与连续正文 | `daodejing.bamboo` |
| 单面朱丝栏、缩进、重点旁线 | 模板、颜色与字格缩进 | `custom.json` |
| 横排正文和双行小注 | 横排方向、双行夹注 | `horizontal.bamboo` |
| 随段讲解的段后注 | 独立小字号段落，与前段关联 | `horizontal.bamboo`、`annotations.json` |
| 朱色短旁注 | ruby 配对基文与注文 | `annotations.json` |
| 栏间长旁批 | 源锚点、独立区域、段落相对文字框 | `annotations.json` |
| 正文上方双栏眉批 | 顶部区域与所在页面锚点 | `annotations.json` |
| 页下注与编号 | DOCX 原生脚注部件 | `((…))` 标记与脚注测试 |
| 正文编号引用与随段注文 | 一个关联对象，自动编号，Word 编号列表和 REF 回链 | `numbered.json` |

验收关注文字完整、方向正确、注释关系以及重排后的遮挡和错页。密集朱批必须明确留出行栏间距与上方空间。

## 批注区域

版心、鱼尾、书名、卷次、页码、边线、外框和界栏均可关闭。新建编辑文档默认不包含这些元素；只有明确应用预设或启用某项时才显示。

## 编号与标签

`numbered_note` 行内对象保存稳定 `target`、注文 `text`、可选注家标签 `annotation` 和 `boxed`。正文引用和注文的标号由出现顺序派生，用户不用手工维护“【一】”。每个对象对应一条引用与一条随段注文，当前不是多处引用同一条注释的共享图模型。

Word 使用中文编号列表与书签，正文使用 REF 域引用对应段落编号。Word 内编辑后可更新域来刷新引用。导入器读取实际编号注文和域关联，不用过期的源文快照替代正文。标签使用独立字符样式和可选字符边框。

## 矢量符号

实心、空心、双线、凹口、分瓣和阶形鱼尾分别支持上、下、左、右方向。它们是独立绘图原语，没有绑定 `E101` 等字体私用区码位，也不是特定字体全部字形的逐项复刻。若以后导入字体符号，需要同时保存字体来源、字形标识和回退方案。

## 旁批锚点

```json
{
  "text": "此處為隨文批語",
  "block": 1,
  "inline": 0,
  "offset": 3,
  "placement": "side",
  "columns": 1,
  "extent": 12
}
```

该配置锚定第二段、第一段行内文字中的第四个码点。`extent` 是每条小字流的容量，`columns` 是小字流数量。竖排先读右列，横排先读上行。`top` 区域需预留足够的上边距。

短旁注最多锚定 8 个码点、注文 16 个码点，避免把长段文字塞进不能任意拆分的 ruby 单元。更长的批语使用独立区域。固定布局检查与正文的冲突；Word 中改字后仍需复核长框。

## 流式边界

正文、夹注、短旁注和脚注能由 Word 随文字重新布局；段后注是可续页的小字段落。

独立长批注不是 Word 的第二条跨页正文流。它是与段落或页面关联的可编辑文字框，容量在导出前检查，不自动分裂到下一页。跨页续批需要后续增加续注链、注释分页器和各格式降级契约。

脚注在 PDF/HTML 中当前为随文双行小注，在 DOCX 中为原生页下注，这是已记录的差异，尚未达到位置一致。

## 尚未实现

抬头与自动包边、印章叠印、删改字与校勘异文、复杂表格、族谱连线、工尺谱、完整中西文混排、全套标点禁则、跨页长批注避碰和印刷拼版仍需独立实现。

这些能力不能只靠模板解决：族谱需要关系图与跨页连线，工尺谱需要音符和拍点对齐，自动续批需要多文字流分页协调。新增能力应先定义语义和验收条件，再接入三种导出。


## 题签、署名与印章

题签封面是独立页面类型：主标题和卷次共用居中的竖向题签，字号按可用高度缩小，不能在可读字号下容纳时返回诊断。边框可关闭或选择单、双线。正文中的作者署名、题跋落款使用较小字号和栏末/行末对齐，诗文可使用段内换行保留分行。

文字方印将印文按列从右向左排成方阵，支持红字朱文与白字红底白文。它是文字与框线组合，不是篆刻字体或图像印章。PDF/HTML 使用矢量几何，DOCX 使用行内可编辑文字框。鱼尾与印章都不强制显示。
